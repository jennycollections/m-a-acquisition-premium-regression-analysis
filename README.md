## Data Sources

### 1. SDC Platinum
- **Description:** M&A transaction data, including Acquiror Nation and Target Nation.
- **Source:** [Refinitiv](https://www.lseg.com/en/data-analytics)
- **Access:** Requires institutional access (university subscription).

### 2. Kogut & Singh Cultural Distance Index
- **Description:** Measures cultural distance between countries.
- **Source:** [Prof. Li's Homepage – Download CSV](https://www.mgt.tum.de/fileadmin/user_upload/Kogut_Singh_index.csv)
- **Access:** Publicly available.

### 3. CEPII GeoDist
- **Description:** Provides geographical distance measures between country pairs.
- **Source:** [CEPII Official Database](https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=6)
- **Access:** Publicly available.
